Keyboard-centric application and window switcher for macOS. Seamlessly manage apps and windows with precision, optimized for macOS 11.5 Big Sur and later, including full Apple Silicon support.

Quick Application Switching

Select apps instantly using number keys. No more cycling through lists—jump directly to what you need.

Effortless Window Management

Switch between windows of the active app with a single Z or ~ key after invoking the switcher. Stay in flow without mouse dependency.

Isolated Workspaces

How It Works

1. Invoke the Switcher

Press your custom hotkey—Command-Tab by default—to open the enhanced switcher instantly.

2. Select Application

Use number keys (1-9) for quick app selection or arrow keys for navigation.

3. Switch Windows

Press Z or ~ to cycle through the app's windows on the current Space.

4. Release to Confirm

Release the modifier key to switch; everything happens keyboard-only.
